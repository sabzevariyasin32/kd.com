# KD | King Developer - وب‌سایت رسمی و پرتفولیو

وب‌سایت رسمی برند شخصی **KD (King Developer)** با طراحی مدرن، تیره (Dark Obsidian)، سریع و کاملاً مستقل از سرور، آماده برای میزبانی رایگان روی **GitHub Pages**.

> **شعار برند:** Turning Ideas Into Digital Reality (تبدیل ایده‌ها به واقعیت دیجیتال)

---

## 📁 ساختار فایل‌های پروژه

```text

├── src/

│   ├── data/
│   │   ├── config.ts            # اطلاعات تماس، هویت برند، شبکه‌های اجتماعی و خدمات
│   │   └── projects.ts          # اطلاعات کامل نمونه‌کارها و پروژه‌ها
│   ├── components/
│   │   ├── Header.tsx           # هدر با استاندارد سه‌بخشی و منوی موبایل
│   │   ├── Hero.tsx             # بخش هیرو با المان سه‌بعدی اختصاصی KD
│   │   ├── About.tsx            # معرفی شفاف بدون رزومه‌سازی کاذب
│   │   ├── Skills.tsx           # کارت‌های مهارت بدون درصد ساختگی
│   │   ├── Projects.tsx         # فیلتر دسته‌بندی، جستجو و نمایش کارت‌ها
│   │   ├── ProjectDetailModal.tsx # مدال بررسی عمیق جزئیات هر پروژه

│   └── main.tsx                 # راه‌انداز React 19
```

## 🚀 راهنمای اجرای محلی (Local Development)

برای اجرای سایت روی کامپیوتر شخصی:

1. نصب بسته‌ها:
   ```bash
   npm install
   ```

2. اجرای سرور توسعه:
   ```bash
   npm run dev
   ```

3. مرورگر را باز کرده و به آدرس نمایش داده شده (معمولاً `http://localhost:3000`) مراجعه کنید.

## 🌐 آموزش انتشار رایگان روی GitHub Pages

این وب‌سایت کاملاً استاتیک است و نیازی به خرید هاست یا دیتابیس ندارد:

### گام اول: ساخت مخزن در GitHub
1. وارد حساب خود در [GitHub](https://github.com) شوید.
2. روی دکمه **New Repository** کلیک کنید.
3. اگر می‌خواهید آدرس سایت شما `https://username.github.io` باشد، نام مخزن را دقیقاً برابر با `username.github.io` قرار دهید. در غیر این صورت، نام دلخواه بگذارید (مانند `kd-portfolio`).
4. وضعیت را روی **Public** قرار دهید و مخزن را بسازید.

### گام دوم: ارسال کدهای پروژه
در ترمینال سیستم خود:
```bash
git init
git add .
git commit -m "Initial commit for KD portfolio"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

### گام سوم: ساخت خروجی نهایی (Build)
```bash
npm run build
```
پوشه `dist` تولید خواهد شد.

### گام چهارم: فعال‌سازی در GitHub
در صفحه مخزن گیت‌هاب:
- به مسیر **Settings** > **Pages** بروید.
- در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
- شاخه انتشار (Branch) را انتخاب کرده و دکمه **Save** را بزنید.
- آدرس سایت اختصاصی شما در بالای همان صفحه نمایش داده می‌شود.

## 🛠️ نحوه ویرایش اطلاعات و افزودن پروژه‌ها

1. **تغییر اطلاعات تماس:** به سادگی فایل `src/data/config.ts` را باز کنید و آیدی تلگرام، ایمیل یا شماره تماس را ویرایش کنید.
2. **افزودن پروژه جدید:** از طریق دکمه «استودیو مدیریت محلی» در هدر سایت می‌توانید پروژه جدید اضافه کنید، خروجی JSON آن را با یک کلیک کپی کرده و در `src/data/projects.ts` قرار دهید.
